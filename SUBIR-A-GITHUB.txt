━━ 5 · CÓMO SUBIRLO ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Por la web de GitHub
    1. Entra al repositorio → botón «Add file» → «Upload files».
    2. Arrastra la carpeta completa (menos las dos de arriba).
    3. GitHub respeta las subcarpetas al arrastrar.
    4. Escribe el mensaje: «Rediseño editorial» y confirma.
    5. En 1–2 minutos está en vivo.

  Por Git, si lo tienes instalado
    git add -A
    git commit -m "Rediseño editorial"
    git push

  Antes de subir, añade esto al .gitignore para no cargar los 29 MB:

    _originales-fotos/
    _revision/


━━ 6 · OJO CON ESTO ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Esta carpeta tiene las rutas en RELATIVO, para poder abrirla con
  doble clic. Lo que publicas hoy en internet es  web/dist/ , que
  las tiene en ABSOLUTO. Son dos cosas distintas.

  Si tu repositorio publica esta misma carpeta, sube tal cual.
  Si publica web/dist/, hay que trasladar los cambios allá:
  es el mismo HTML, sólo cambian las rutas (./assets/ pasa a
  /assets/). Dímelo y lo dejo hecho.

  Y después de subir, abre el sitio con Ctrl+F5 la primera vez:
  el navegador guarda el CSS viejo.
